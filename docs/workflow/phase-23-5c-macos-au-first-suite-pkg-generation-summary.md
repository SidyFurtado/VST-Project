# Phase 23.5C - macOS AU-First Suite PKG Generation

Date: 2026-06-04

## Objective

Create the first macOS AU-first installer package for the ASTRA Audio Suite, containing only the Audio Unit versions of the three active plugins:

- `AUREQ.component`
- `LUMINAR.component`
- `GRAVITY.component`

Install destination:

```text
/Library/Audio/Plug-Ins/Components/
```

## Created Structure

```text
installer/macOS/au-first-suite/
  payload/
    Library/Audio/Plug-Ins/Components/
      AUREQ.component
      LUMINAR.component
      GRAVITY.component
  resources/
    welcome.html
    license.html
    README.txt
    background.png
  distribution/
    Distribution.xml
  output/
    ASTRA-Audio-Suite-0.9.0-rc1-macOS-AU-component.pkg
    ASTRA-Audio-Suite-0.9.0-rc1-macOS-AU.pkg
    expanded_pkg_validation_clean/
```

## Source Components

- `build/plugins/01_EQ/AUREQ_artefacts/AU/AUREQ.component`
- `build/plugins/02_AIR/LUMINAR_artefacts/AU/LUMINAR.component`
- `build/plugins/03_GRAVITY/GRAVITY_artefacts/AU/GRAVITY.component`

## Package Commands

```bash
pkgbuild --identifier br.com.sidyfurtado.astra-suite.au \
  --version 0.9.0 \
  --root installer/macOS/au-first-suite/payload \
  --install-location / \
  installer/macOS/au-first-suite/output/ASTRA-Audio-Suite-0.9.0-rc1-macOS-AU-component.pkg

productbuild \
  --distribution installer/macOS/au-first-suite/distribution/Distribution.xml \
  --package-path installer/macOS/au-first-suite/output \
  --resources installer/macOS/au-first-suite/resources \
  installer/macOS/au-first-suite/output/ASTRA-Audio-Suite-0.9.0-rc1-macOS-AU.pkg
```

The final package was regenerated after cleaning the staging payload with:

```bash
xattr -cr installer/macOS/au-first-suite/payload
dot_clean -m installer/macOS/au-first-suite/payload
```
