# AUREQ 0.9.0-rc1 — Known Limitations

This document lists expected limitations for the private macOS beta.

## Security / Gatekeeper

- The beta is unsigned.
- The beta is not notarized.
- macOS may show security warnings.
- Public release requires Apple Developer ID signing and Apple notarization.

## DMG

- The DMG is functional and contains the installer, README, icon, and background asset.
- Finder window polish/background placement is still partial/best effort.
- This does not affect installation.

## Platform Scope

- macOS VST3 is the current priority.
- Windows installer is not available yet.
- AU is not available yet.
- AAX is not available yet.
- Logic Pro is not a direct VST3 target; Logic support requires AU or a wrapper in a future phase.

## Beta Scope

- This is a private beta, not a public release.
- The package is intended for controlled testing with selected users.
- Please report DAW version, macOS version, Mac CPU type, screenshots/videos, and reproduction steps for any issue.
