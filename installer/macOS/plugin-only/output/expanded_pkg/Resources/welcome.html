Bem-vindo ao AUREQ

O AUREQ é um equalizador paramétrico premium da ASTRA Audio Suite, desenhado para precisão absoluta e fluxo de trabalho avançado.

Nesta versão (0.9.0-rc1):

  • Processamento em 64-bit float e oversampling integrado
  • Curvas de filtro premium e Dynamic EQ
  • Latência zero mode
  • Preset Browser focado em gêneros musicais
  • Interface Glassmorphism de alta resposta

Este instalador copiará o plugin VST3 para a pasta nativa do seu Mac (/Library/Audio/Plug-Ins/VST3), garantindo que sua DAW favorita (Ableton Live, Logic Pro, Cubase, etc) o encontre imediatamente.

Obrigado por escolher ASTRA Audio!
