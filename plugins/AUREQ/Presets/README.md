# Clean EQ - Presets Iniciais (plugins/01_EQ/Presets)

Esta pasta conterá as predefinições de equalização específicas para mixagem e masterização.

## Tipos de Presets Previstos
*   **Factory Presets (Predefinições de Fábrica)**:
    *   `Default`: Configuração neutra (curva flat, todas as bandas em 0 dB).
    *   `Vocal Clean-up`: Corte de graves (HPF) e leve atenuação em frequências médias-graves com Q amplo.
    *   `Kick Punch`: Destaque de transiente grave com ganho estreito e corte de ressonâncias de caixa acústica.
    *   `Master Air Boost`: Ganho sutil e musical em formato High-shelf nas altas frequências (acima de 12 kHz) para dar ar e clareza.
*   **User Presets**:
    *   Estrutura de pasta no diretório do usuário gerenciada pela classe de serialização XML para carregar configurações salvas manualmente.
