# Plugin 01_EQ: Equalizador Paramétrico

Este diretório contém a estrutura e os arquivos para o desenvolvimento do Equalizador Paramétrico.

## Objetivo
Desenvolver um plugin de equalização paramétrica multibanda com curvas de filtro precisas (Bell, Shelving, Passa-Alta, Passa-Baixa) com processamento de áudio digital de alta qualidade em tempo real.

## Estrutura do Plugin
*   **`Source/`**: Ponto de entrada C++ principal e gerenciador do plugin.
*   **`DSP/`**: Algoritmos de processamento de áudio, equações e filtros.
*   **`UI/`**: Controles de tela, knobs dourados, meters e design system específico.
*   **`Presets/`**: Presets e predefinições de equalização de fábrica.
*   **`Tests/`**: Casos de teste de filtros e validações.
*   **`Docs/`**: Documentações específicas sobre o design de filtros deste EQ.
